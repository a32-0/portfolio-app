# Armando Rojano Portfolio

Personal portfolio of Armando Rojano, Product Designer.

**Live site:** [armando-rojano.vercel.app](https://armando-rojano.vercel.app)

## Built with

Next.js, React, TypeScript, Tailwind CSS, and Vercel.

## Running locally

```bash
pnpm install
pnpm dev
```
